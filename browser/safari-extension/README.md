# dbrain Safari Extension

Safari supports WebExtensions, but unlike Chrome it packages them inside a
small macOS/iOS host app generated by Xcode. The dbrain extension source lives
in `../chrome-extension` and is intentionally WebExtension-compatible so the
same click behavior can be packaged for Safari.

## Generate the Xcode project

First make sure Xcode has completed first-launch setup:

```sh
xcodebuild -runFirstLaunch
```

Then generate a macOS Safari Web Extension project:

```sh
browser/safari-extension/create-xcode-project.sh
```

The generated project is written to:

```text
browser/safari-extension/build/dbrain-link-saver-safari/
```

The script references the shared extension resources instead of copying them, so
changes under `browser/chrome-extension` are picked up by the generated Safari
project.

## Install locally

1. Open the generated Xcode project.
2. Select a local signing team if Xcode asks.
3. Run the macOS host app target.
4. In Safari, enable developer extensions if needed:

   ```sh
   Safari > Settings > Advanced > Show features for web developers
   Develop > Allow Unsigned Extensions
   ```

5. Open `Safari > Settings > Extensions` and enable **dbrain Link Saver**.
6. Open the extension options, set the dbrain base URL, and allow access to that
   origin when Safari prompts.

The toolbar button posts the active tab URL to `POST /api/links` with
`{ "url": "...", "enrich": false }`. If dbrain web auth is enabled, log in to
dbrain in Safari first; a `401` opens the dbrain login page.
