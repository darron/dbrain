# dbrain Security Review Ledger

## Executive Summary

This document is the sanitized working ledger for a full security and supply-chain review of the `dbrain` checkout. It records the initial source inventory, threat model, required abuse hypotheses, evidence state, commands, and coverage. It is not a final assessment.

At ledger creation, no candidate is confirmed, no vulnerability severity is assigned, and no runtime impact has been demonstrated. Inventory citations identify current source registrations and advertised controls; they do not prove that a control dominates every caller or rejection path.

## Threat Model

### Assets And Invariants

- Authoritative local SQLite corpus, raw imported evidence, rendered Markdown, media, OKF bundles, research traces, configuration, credentials, OAuth/MCP/tsnet state, backups, and release/publication authority.
- Local-first authority: remote services provide import, inference, archive, or transport, not primary truth.
- Import-only authority: native integrations must not mutate upstream apps.
- Raw evidence remains distinct from model-derived summaries/OCR/plans, and model prose is not authoritative evidence.
- MCP is intended to remain read-only; web and administrative CLI paths can mutate local state only within their explicit identity and confirmation boundaries.

### Attacker And Input Classes

| Class | Prerequisite / control | Trust transition and potential authority |
|---|---|---|
| Local user or local process | Shell, filesystem, config, or IPC access under the dbrain user | Supplies CLI/config/env/paths and can trigger destructive, listener, archive, install, or helper operations |
| Remote caller | Reachability to web, reverse proxy, tsnet, Funnel, or MCP HTTP | Crosses network-to-corpus boundary; may read private data, consume resources, or invoke mutations depending on auth |
| Authenticated client | Valid OAuth session, service signature, MCP bearer, or tailnet reachability | Gains the authority assigned to the authenticated surface; capability breadth and replay matter |
| Hostile origin or browser extension | Ability to issue browser requests or extension messages | Crosses browser-origin checks into mutation routes; extension scheme/host is not identity by itself |
| Hostile imported content | Controls a note, tab, post, feed, URL, file, metadata field, or embedded media | Moves through parser, path, renderer, search, prompt, public-share, and subprocess boundaries |
| Malicious remote service, model, archive, or helper | Controls HTTP response, redirect/DNS result, model/helper output, object bytes, or executable behavior | Returns data that may become persisted evidence, paths, commands/errors, active content, or replacement state |
| Corrupt database | Can supply/restore or locally alter structurally invalid or malicious-valid SQLite state | Converts persisted rows into filesystem paths, archive keys, rendered output, queries, deletions, or migrations |
| Symlink/path attacker | Can create/replace paths or influence DB/config-derived path components | Crosses lexical root checks and time-of-check/time-of-use boundaries into reads, writes, renames, or deletion |

Irreversible effects include corpus replacement or deletion, upstream mutation, local file deletion, credential/publication misuse, public disclosure, and release compromise. Reversible but material effects include private-data exposure, durable derived-data contamination, archive pollution, resource exhaustion, and denial of local service.

### White-Box Traces And Refutation Records

- **SEC-001 — DB-derived path escape.** `media_assets.local_path` is selected without a path invariant (`internal/store/media_archive_candidates.go:15-55,79-92`), then joined under `cfg.VaultDir` and opened for upload (`internal/mediaarchive/s3.go:49-69`) or removed after only same-path archive-status checks (`internal/mediaarchive/prune.go:19-43`). Item/source note writers also join persisted `NotePath` directly before read/write (`internal/vault/item.go:14-31`; `internal/vault/source.go:23-40`). Normal download paths are content-hash-derived, but that does not dominate restored or corrupt rows. **False if** every persisted/restored path is canonically validated below its root or every sink rejects traversal and symlink escape. Task 7 must insert traversal and symlink paths in a synthetic DB and prove both rejection and normal upload/prune behavior.

- **SEC-002 — Apple Notes attachment containment.** Path decoding accepts `file://`, home-relative, absolute, and slash-containing values (`internal/applenotes/reader_attachment_paths.go:37-73`); resolution accepts absolute paths and cleans DB-relative joins without containment (`internal/applenotes/attachment_copy.go:14-27`); the result reaches `os.Stat`/`os.Open` and extraction (`attachment_copy.go:29-47`; `attachments.go:125-187`). The existing OCR test supplies an arbitrary absolute path and observes extraction (`internal/applenotes/attachments_test.go:14-63`). Regular-file and 50 MiB checks are positive controls, not containment. **False or materially weaker if** real Apple Notes rows cannot be influenced to contain attacker-selected paths. Task 7 must use a synthetic snapshot for contained, absolute, traversal, and symlink cases; remote-collaborator influence remains excluded.

- **SEC-003 — outbound destination policy.** Feed fetching uses a public-IP-only dialer, bounded redirects, and wire/decoded limits (`internal/feedimport/http.go:33-55,105-132,144-174`), and focused localhost rejection/explicit opt-in tests pass. Source enrichment instead uses ordinary clients and requests arbitrary extracted URLs (`internal/sourceenrich/reader.go:15-48`; `internal/sourceenrich/http_fetch.go:10-79`); media download sends `RemoteURL` with a normal redirect-following client (`internal/mediadownload/run.go:45-61`; `download.go:28-36`). **False for a caller if** every initial and redirected destination passes a public-IP policy or the destination is operator-trusted. Task 7 must test loopback/private/link-local/IPv6 and redirected targets while preserving explicit local-provider/configured-endpoint paths.

- **SEC-004 — missing resource bounds.** Media bytes stream through unrestricted `io.Copy` (`internal/mediadownload/download.go:59-93`); SQLite restore download and gzip expansion are unbounded (`internal/sqlitearchive/restore.go:55-93`; `internal/sqlitearchive/files.go:38-55`); representative helper callers buffer all stdout/stderr. Feed and Apple attachment paths demonstrate appropriate byte-plus-one controls. **False for a sublane if** a caller-level or sink-level byte/item/output cap dominates it. Task 7 must use small over-limit streams, a compact high-ratio gzip, and fake helper output; no high-load test is authorized.

- **SEC-005 — foreign SQLite restore.** Restore downloads, decompresses, and runs only `PRAGMA quick_check` before moving the current DB/WAL/SHM aside and renaming the candidate into place (`internal/sqlitearchive/restore.go:55-119`; `sqlite.go:30-45`; `files.go:73-89`). The existing test creates a database containing only `test_values`, restores it, and confirms replacement (`internal/sqlitearchive/run_test.go:82-145,226-259`). CLI confirmation is a positive control, but it does not validate application identity. **False if** a valid foreign schema is rejected before replacement; observed existing behavior contradicts that. Task 7 must repeat with corrupt, foreign-valid, expected dbrain, and malicious-row fixtures and verify rollback/authorized restore.

- **SEC-006 — local permissions.** General runtime directories are created `0755`, vault notes and metrics `0644`, while installer config, research traces, and tsnet state have restrictive controls. **False as a disclosure claim if** effective ancestors and ownership prevent another local user from reading the leaf. Effective ancestor modes, umask, DB mode, overwrite behavior, and the local multi-user threat model were not verified, so this remains a gap rather than a vulnerability.

- **SEC-007 — warning-only public exposure.** Funnel option validation checks TLS and supported ports (`internal/remote/options.go:137-164`). Disabled web auth passes public-auth validation (`web/auth_config.go:114-124`), MCP auth defaults disabled (`internal/mcpserver/auth.go:22-38`), both handlers are still built (`internal/remote/server_handler.go:23-70`), and startup emits warnings before/after public listening (`internal/remote/server.go:122-124,168-184`). **False if** a higher-level guard rejects Funnel unless each enabled surface has authentication; none was found. Task 7 must table-test web-only, MCP-only, and combined Funnel options before node startup, plus authenticated controls.

- **SEC-008 — cross-origin local mutation.** When web auth is disabled, the local web handler returns its mux directly (`web/server.go:194-230`) and has no origin guard. `/api/tag` and `/api/links` decode JSON and mutate/import without requiring JSON Content-Type (`web/mutation_handlers.go:15-119`), allowing a browser-simple `text/plain` request shape. The remote wrapper has an origin guard, but accepts missing Origin and any nonempty Chrome/Safari extension origin for `/api/links` (`internal/remote/handler.go:60-108`). **False for a deployment if** browser Private Network Access or another trusted proxy always blocks the request; no application guard establishes that. Task 7 must use handler tests with hostile/same/no Origin, Host changes, text/plain JSON, and explicit extension controls and assert no side effects on rejection.

- **SEC-009 — auth lifecycle and replay.** OAuth state, approval, session expiry/removal, logout, and cookie flags have strong source controls. The residual service header includes timestamp and nonce, but verification checks only skew, nonempty nonce, and HMAC; no nonce cache exists (`internal/serviceauth/serviceauth.go:21-80`). Its authority is restricted to `/api/doctor/full-disk-access` (`web/auth.go:350-364`). **False if** repeated identical signed headers are rejected by a dominating stateful layer; none was found. Task 7 must send the same signed header twice, preserving wrong-route/method, stale/future, and distinct-nonce controls.

- **SEC-010 — MCP amplification.** HTTP body size defaults to 8 MiB (`internal/mcpserver/http.go:98-103,187-200`), but JSON-RPC arrays have no element cap and every entry is dispatched (`internal/mcpserver/protocol.go:25-45`). Fifteen tools are reachable, including model-assisted research planning by default (`internal/mcpserver/tools.go:18-50`; `research.go:15-60`). Both HTTP server paths open the SQLite store read-only, a verified positive control. **False if** an aggregate batch/work/response limit dominates dispatch; only empty-batch rejection and per-tool caps were found. Task 7 must instrument dispatch/planner counts and test max-plus-one rejection before work.

- **SEC-011 — public-share URL leakage.** Public shares are anonymous and render persisted original URLs (`web/chat_shares.go:118-154,925-930`). `publicExternalURL` blocks protected paths and literal local/private hosts, but preserves URL userinfo and query data (`chat_shares.go:644-673`). **False if** upstream canonicalization strips secrets on every path into `OriginalURLs`; no dominating sanitizer was found. Task 7 must use userinfo plus token/key/signature/X-Amz sentinels and assert absence from stored input, metadata, and anonymous HTML while defining policy for ordinary query URLs.

- **SEC-012 — subprocesses.** Representative summarizer, OCR, ffprobe, and launchctl callers use direct argv, refuting shell-metacharacter execution for those paths. Broad inherited environment and unbounded stdout/stderr remain under SEC-004. **False as a broader claim only if** all helper callers have controlled executables/environment, bounded output, private temp state, timeout/descendant cleanup, and redaction; that inventory is incomplete.

- **SEC-013 — model authority.** Raw fields and derived summary/OCR/enrichment provenance are structurally separate, summary persistence does not overwrite raw item fields, and categorization applies tags only under explicit `Apply`. Untrusted raw/derived content is still concatenated into later prompts, so prompt separation and provider minimization remain defense-in-depth questions. **False as a raw-evidence corruption claim if** every output sink preserves these structural separations; inspected paths do, but provider and downstream coverage is incomplete.

- **SEC-014 — release dependency mutability.** Tag-triggered artifact jobs execute mutable `actions/setup-node@v4` and `go-task/setup-task@v2` before rebuilding UI/binaries (`.github/workflows/release.yaml:3-6,83-157`); SHA-pinned upload/download actions later publish those bytes (`release.yaml:159-202`). **False if** those selectors are immutable or an independent source-bound attestation/rebuild dominates publication; neither is present in checkout source. This is probable High only under third-party action tag compromise, not confirmed. `golangci-lint@latest`, absent SBOM/attestation, PR-CI mutable tooling, and external Homebrew/OIDC settings are separate hardening/gap records. npm lock integrity, clean frontend generation, and several pinned actions are positive controls.

- **SEC-015 — launchd drift.** Checkout generation resolves an absolute binary and selector, XML-escapes values, includes only a fixed `PATH`, and focused default/root/config-file plist tests pass. This refutes direct checkout-generator secret embedding or selector drift. **False for installed/runtime state only if** the generated plist, mode, executable/config identity, environment, and listener defaults match checkout behavior; those excluded artifacts remain a coverage gap.
