## Threat Model

### Assets And Invariants

- Authoritative local SQLite corpus, raw imported evidence, rendered Markdown, media, OKF bundles, research traces, configuration, credentials, OAuth/MCP/tsnet state, backups, and release/publication authority.
- Local-first authority: remote services provide import, inference, archive, or transport, not primary truth.
- Import-only authority: native integrations must not mutate upstream apps.
- Raw evidence remains distinct from model-derived summaries/OCR/plans, and model prose is not authoritative evidence.
- MCP is intended to remain read-only; web and administrative CLI paths can mutate local state only within their explicit identity and confirmation boundaries.

### Attacker And Input Classes

| Class | Prerequisite / control | Trust transition and potential authority |
|---|---|---|
| Local user or local process | Shell, filesystem, config, or IPC access under the dbrain user | Supplies CLI/config/env/paths and can trigger destructive, listener, archive, install, or helper operations |
| Remote caller | Reachability to web, reverse proxy, tsnet, Funnel, or MCP HTTP | Crosses network-to-corpus boundary; may read private data, consume resources, or invoke mutations depending on auth |
| Authenticated client | Valid OAuth session, service signature, MCP bearer, or tailnet reachability | Gains the authority assigned to the authenticated surface; capability breadth and replay matter |
| Hostile origin or browser extension | Ability to issue browser requests or extension messages | Crosses browser-origin checks into mutation routes; extension scheme/host is not identity by itself |
| Hostile imported content | Controls a note, tab, post, feed, URL, file, metadata field, or embedded media | Moves through parser, path, renderer, search, prompt, public-share, and subprocess boundaries |
| Malicious remote service, model, archive, or helper | Controls HTTP response, redirect/DNS result, model/helper output, object bytes, or executable behavior | Returns data that may become persisted evidence, paths, commands/errors, active content, or replacement state |
| Corrupt database | Can supply/restore or locally alter structurally invalid or malicious-valid SQLite state | Converts persisted rows into filesystem paths, archive keys, rendered output, queries, deletions, or migrations |
| Symlink/path attacker | Can create/replace paths or influence DB/config-derived path components | Crosses lexical root checks and time-of-check/time-of-use boundaries into reads, writes, renames, or deletion |

Irreversible effects include corpus replacement or deletion, upstream mutation, local file deletion, credential/publication misuse, public disclosure, and release compromise. Reversible but material effects include private-data exposure, durable derived-data contamination, archive pollution, resource exhaustion, and denial of local service.
